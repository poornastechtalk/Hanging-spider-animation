# 🕷️ 3D Hanging Spider – ASCII Animation

An advanced creative Python animation that visualizes a hanging spider using a 3D point cloud rendered as ASCII characters.

## ✨ Project Overview

This project creates a detailed 3D spider model using mathematical geometry and point-cloud rendering. The spider gradually reveals itself through animated ASCII characters, then gently swings and rotates while displaying a cinematic decoding effect.

The rendering process uses a depth buffer to determine which points are visible from the current viewing angle.

## 🚀 Features

- 🕷️ Detailed 3D spider model with eight legs
- 🔵 Point-cloud-based 3D rendering
- 💻 ASCII character-based visual representation
- ✨ Gradual character reveal animation
- 🌌 Decoding-style glyph effects
- 🔄 Smooth swinging and rotation
- 💡 Directional lighting and brightness layers
- ❄️ Cool blue and ice-white colour palette
- 📊 Animated swing and rotation information

## 🛠️ Technologies Used

- Python
- Turtle Graphics
- Tkinter Canvas
- Mathematical calculations
- Random Module

## 📋 Requirements

- Python 3
- Tkinter support

No NumPy or additional third-party packages are required.

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Run the following command:

```bash
python hanging_spider.py
```

4. Watch the spider gradually appear and animate!
